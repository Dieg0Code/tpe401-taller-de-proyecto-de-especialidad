# Documentos del aula virtual

Los instrumentos oficiales del módulo, tal como se publican en el aula virtual de AIEP.

- `actividades/`: las páginas de cada actividad del aula, con sus orientaciones: la bienvenida, la
  Ficha de Actividad N.º 1 y la elección del desafío, los avances de los Entregables I y II, el
  portafolio y el examen final.
- `formatos/`: las plantillas que se completan y se entregan: el documento «Entregable Parte I», el
  Anexo Carta Gantt, el Lienzo Canvas, la cadena de valor, el Elevator Pitch y el Resumen Ejecutivo.
- `instructivos/`: cómo se elabora y se entrega cada pieza: el Elevator Pitch, el Canvas y la
  cadena de valor, el Entregable II, el portafolio y el Resumen Ejecutivo.
- `pautas/`: las pautas con que se revisa cada entrega: los avances, el Entregable I, el
  Entregable II, el portafolio y la presentación del Resumen Ejecutivo.
