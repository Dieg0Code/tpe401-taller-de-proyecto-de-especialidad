# Documentos del aula virtual

Los instrumentos oficiales del módulo, tal como se publican en el aula virtual de AIEP.

## Aplicación en este módulo

Por indicación del docente, **el contacto con la organización no es condición para comenzar ni
para entregar el proyecto**. Mientras se gestiona, se trabaja con los casos reales de organizaciones
de la zona que entrega el docente, fuentes citadas y supuestos explícitos y justificados. Si
posteriormente se habilita el contacto, el equipo contrasta los supuestos y actualiza la propuesta
y el software. Si no se concreta, entrega con las evidencias disponibles y los pendientes de
validación declarados. Esta adaptación se desarrolla en las guías y el cronograma; los archivos
oficiales se conservan como fuente.
